# 🎨 Interactive 2D Animated Environment using OpenGL

A comprehensive **Computer Graphics course project** developed using **C++ and OpenGL (GLUT)** that showcases a fully animated 2D interactive environment.  
The project demonstrates the practical implementation of core computer graphics concepts including animation, transformations, lighting effects, weather simulation, object rendering, and real-time scene transitions.

The environment combines natural landscapes, animated activities, dynamic weather conditions, transportation systems, sports interactions, and day-night transitions into a single cohesive graphical simulation.

---

# 📌 Project Overview

This project was created as part of a **Computer Graphics** course to demonstrate the application of OpenGL rendering techniques and animation principles in a real-time graphical environment.

The scene includes:

- Dynamic environmental transitions
- Animated natural and urban elements
- Real-time movement and object interactions
- Weather simulation
- Multiple activity zones
- Interactive animation sequences

The project focuses on combining artistic scene design with computational graphics techniques.

# ▶️ Compilation & Execution

## Requirements

Before running the project, ensure the following are installed:

- OpenGL
- GLUT / FreeGLUT
- C++ Compiler (g++, MinGW, MSVC)

---

## Compile using g++

### Linux

```bash
g++ main.cpp -o graphics_project -lglut -lGLU -lGL
./graphics_project
```

---

### Windows (MinGW)

```bash
g++ main.cpp -o graphics_project.exe -lfreeglut -lopengl32 -lglu32
graphics_project.exe
```
